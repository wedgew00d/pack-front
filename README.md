# 背嚢戦線 PACK FRONT

バッグに詰めた物だけが戦う、縦画面のインベントリ管理型オートバトラー。
準備（ショップとバッグ整理）と自動戦闘を繰り返し、10波の襲撃から防壁を守る。

## 遊び方

- ショップの品をドラッグしてバッグへ入れると購入。待機スペースに置いた物は戦闘に参加しない。
- 補助アイテムは、上下左右に隣り合う武器を強化する（境目に◆印が付く）。
- 同じ物を重ねると合成して Lv が上がる（Lv3 まで）。
- 回転は、ドラッグ中に R キーか右クリック（スマホは、ドラッグ中に別の指でタップ）。
- 「出撃」を押すと戦闘は自動で進む。速度は ×1〜×3。
- 音量は、タイトルと中断メニューのつまみで変える。

Windows のブラウザとスマホ（縦持ち）が対象。

## 構成

ビルドなし。リポジトリ直下をそのまま配信する。

| 場所 | 中身 |
|---|---|
| `index.html` | 画面の枠と CSS |
| `js/data.js` | アイテム・敵・ウェーブの定義 |
| `js/sim.js` | ルール本体（バッグ、ショップ、戦闘）。画面に依存しない |
| `js/main.js` | 描画と操作 |
| `js/audio.js` | BGM と効果音（Web Audio の合成。音声ファイルなし） |
| `assets/` | 画像（アイテム、敵、敵の移動アニメ、演出、背景）。画像が無い場合はコード描画に戻る |
| `test/bot.js` | 自動対戦。バランスの確認用 |
| `test/shot.py` | ヘッドレスブラウザでの操作の通しと撮影 |
| `tools/build_assets.py` | 生成した元画像を、ゲーム用に切り出し・縮小・変換する |

数値を変えるときは `js/data.js`（アイテムと敵）と `js/sim.js` 冒頭の調整値を触る。変えたら自動対戦で確かめる。

```
node test/bot.js 400 naive   # 空きに詰めるだけのボット
node test/bot.js 400 smart   # 補助を武器の隣に置こうとするボット
```

画像を差し替えるときは、元の PNG を次の構成で用意して変換する（元画像はリポジトリに入れていない）。

```
python3 -I tools/build_assets.py <元のassetsフォルダ> assets
# 元のassets/ items/ enemies/ enemies_anim/ fx/ bg/
```

## 確認用の機能

URL の末尾に `#debug` を付けると、画面上部に次が出る。

- 毎秒のコマ数と、処理時間の内訳、敵・弾・演出の数
- コイン追加、その波に勝つ、防壁全快、次の波へ、最終波へ

## 素材

画像は画像生成（ChatGPT）で作り、`tools/build_assets.py` で加工したもの。音はすべてコードでの合成。
